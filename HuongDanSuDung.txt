   HƯỚNG DẪN CÀI ĐẶT VÀ VẬN HÀNH PHẦN MỀM TỐI ƯU LỘ TRÌNH GIAO HÀNG
           Đề tài: Tiệm bánh "Góc Bếp Mẹ Bắp" - TP.HCM
========================================================================

I. CẤU TRÚC THƯ MỤC DỰ ÁN
- CaiDat/    : Chứa mã nguồn thực thi các thuật toán và hàm chính (.cpp)
- KhaiBao/   : Chứa các file tiêu đề khai báo cấu trúc dữ liệu (.h)
- KetQua/    : Nơi lưu trữ file báo cáo xuất ra (BaoCaoSoSanh.csv)
- .vscode/   : Cấu hình build & debug tự động cho VS Code

------------------------------------------------------------------------
II. CÁC CÁCH BIÊN DỊCH VÀ CHẠY PHẦN MỀM

CÁCH 1: Dùng Terminal trong VS Code / PowerShell / CMD (Khuyên dùng)
- Bước 1: Mở Terminal tại thư mục gốc của dự án.
- Bước 2: Chạy lệnh biên dịch sau (gồm đầy đủ các file .cpp):
    g++ -std=c++17 CaiDat/ChuongTrinhChinh.cpp CaiDat/DocDuLieu.cpp CaiDat/DoHieuNang.cpp CaiDat/ThuatToanThamLam.cpp CaiDat/ThuatToanNhanhCan.cpp -o ChuongTrinhChinh.exe

- Bước 3: Chạy phần mềm:
    + Trên Windows (PowerShell):  .\ChuongTrinhChinh.exe
    + Trên Windows (CMD):         ChuongTrinhChinh.exe
    + Trên Linux / macOS:        ./ChuongTrinhChinh.exe

CÁCH 2: Dùng phím tắt tự động trong VS Code
- Nhấn phím F5 (hoặc chọn menu Run -> Start Debugging).
- VS Code sẽ tự động biên dịch toàn bộ dự án và chạy chương trình trong Terminal.

------------------------------------------------------------------------
III. HƯỚNG DẪN THAO TÁC TRÊN MENU PHẦN MỀM

Khi giao diện menu xuất hiện, nhập số tương ứng và nhấn Enter:

1. [Phím 1] - Chọn bộ dữ liệu thử nghiệm:
   - Nhập 1: Bộ dữ liệu 1 (8 điểm - khu vực gần)
   - Nhập 2: Bộ dữ liệu 2 (10 điểm - khu vực mở rộng)
   - Nhập 3: Bộ dữ liệu 3 (12 điểm - toàn khu vực TP.HCM & lân cận)

2. [Phím 2] - Chạy Thuật toán Tham lam (Greedy / Nearest Neighbor):
   - Hiển thị thứ tự lộ trình giao hàng xuất phát từ tiệm bánh và quay về tiệm.
   - Hiển thị tổng quãng đường (km) và thời gian thực thi (micro giây).

3. [Phím 3] - Chạy Thuật toán Nhánh cận (Branch & Bound):
   - Tìm kiếm lộ trình tối ưu toàn cục (quãng đường ngắn nhất tuyệt đối).
   - Hiển thị lộ trình tối ưu và thời gian thực thi.

4. [Phím 4] - Đo hiệu năng và Xuất báo cáo so sánh:
   - Tự động chạy cả 2 thuật toán trên toàn bộ 3 bộ dữ liệu.
   - In bảng so sánh chi tiết ra màn hình console.
   - Tự động ghi kết quả vào file: KetQua/BaoCaoSoSanh.csv (có thể mở bằng Excel).

0. [Phím 0] - Thoát chương trình.

------------------------------------------------------------------------
IV. XỬ LÝ LỖI THƯỜNG GẶP
1. Lỗi "'g++' is not recognized":
   - Máy tính chưa cài đặt trình biên dịch GCC/MinGW hoặc chưa thêm vào biến môi trường PATH.
   - Cài đặt MinGW-w64 hoặc MSYS2 để sử dụng lệnh g++.

2. Lỗi "undefined reference to...":
   - Xảy ra khi chỉ biên dịch 1 file ChuongTrinhChinh.cpp thay vì biên dịch chung với tất cả các file mã nguồn khác trong thư mục CaiDat/.
   - Hãy chạy đúng câu lệnh biên dịch ở CÁCH 1.

3. Lỗi không tìm thấy file xuất báo cáo CSV:
   - Đảm bảo bạn chạy chương trình từ thư mục gốc dự án để đường dẫn KetQua/BaoCaoSoSanh.csv được xác định chính xác.
